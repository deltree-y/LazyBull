# OOS 滚动窗口离散度参考（P0 测量 A）

> 2026-09-21 测量 / 2026-09-22 归档 · 只读诊断
> 用途：单期前向结果（如"部署模型 + 最近半年 + 纸面"）与 OOS CAGR 对照时的**刻度尺**
> 归档产物：`data/reports/oos_p0_20260921/`（分布汇总 + 窗口序列 + 定位器 + 复跑脚本）

## 1. 问题

"部署模型跑未见时段（如 2026H1）+ 纸面"的结果与 OOS CAGR 不匹配——
在解读差异之前，先量化"单窗口本来能差多少"（固有噪声水平）。

## 2. 方法

- 收益流重建：14 折持仓快照逐日收益拼接（1,686 日，2018-11-28 ~ 2025-12-12），
  与链式绩效同口径（各折内部收益相乘）。
- 校验：日均 9.2440 bps（对照诊断 9.1441）；全期年化 24.01%（对照 23.72%）；
  总倍数 4.219×。
- 滚动窗口（步长 1 天、重叠）年化 = expm1(窗口对数收益 × 252/W)。
- 局限：重叠窗口低估自相关；交易日年化与项目"自然日复合"存在口径小差；
  基准批次含政策层（e2online_r + 回补）——折算的离散度已含政策路径。

## 4. 结论

- **单半年窗口年化的 1σ = 25.7pp**（单季度 57.5pp、单年 16.4pp）。
- ⇒ 单期（≤1 年）前向结果与 OOS CAGR 的任何差异，**首先归于噪声**；
  "**单期不判定**"应成为评估纪律。
- 观察到的"差距"应拆为两部分：**噪声**（时间池化解决）+ **偏差**（可审计：模型配置 /
  链路 / alpha 存活——见 §5.2）。

## 5. 建议（供采纳，尚未实施）

### 5.1 冻结前向档案（forward track record）

1. 部署模型冻结归档（与折模型配置逐项 diff 后登记差异）；
2. 纸面逐日记录（已有）；
3. 评估按多窗口池化（3 个前向窗口 ≈ 噪声从 26pp 降至 ~15pp；6 个 → ~10pp）；
4. 预登记纪律：看过前向结果后**不得**回改部署模型配置（否则档案作废）。

### 5.2 "不匹配"归因三件套

1. **模型/配置 diff**（先例：纸面 v19881（183 列）≠ 基准折模型（140 列）；
   纸面 `max_per_industry=5` vs 回测未启用；`stagger` 1 vs 2）；
2. **链路对照**（同模型、同时段：回测引擎 vs 纸面链路，逐日持仓/成交/净值差异归因）；
3. **alpha 存活检验**（前向期"Top20 相对可买域"超额是否为正——正 ⇒ 归因 regime/执行；
   负 ⇒ 模型层警报）。

### 5.3 追踪指标（月度/季度）

- 滚动 60 日"Top20 相对可买域"超额与命中率（对照本文件的滚动分布方法）；
- 执行账实差（成交价 vs 理论价、涨停未成交率）；
- 数据链路健康（ensure 补齐延迟、freshness 告警）。
