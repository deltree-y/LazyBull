## 5. 机制读数与解释（预登记 §1/§5 要求）

- **位移（全 14 折）**：Top20 集合重叠仅 **26.8%**、每日换入 **14.6 只**；Top30 重叠 32.9%、换入 20.1 只；
  逐位同码比例 1.5%~1.3%（含保留股票的位次重排）。
- **解释**：`分位(score) − λ×风险分位` 在 rank 空间相减——高分位带内 score 差异仅 ~1e-2 级，
  而惩罚差异可达 λ=0.25 级 ⇒ **λ=0.25 已是强倾斜**，机制实际接近"在宽分数带内按低风险重排"；
  这与 smoke 阶段（fold0 重叠 22.6%）推演一致。
- 与"加列实验"对照：本臂**不涉及列集稀释**，负效应全部来自**排序方向本身**——
  与 repurchase / top10fh "把排序往低效方向拽"同一模式，且因惩罚作用于整个排序而更极端。
- 离线快检（2022–2025 采样、候选域 IC(downside)=−0.075）曾是"方向有利"的弱证据，
  但全期 OOS（2018–2026、评估域）平均为**大幅负贡献**；且惩罚列与模型已在用的
  `zscore_volatility_20` 秩相关 ρ≈0.71 ⇒ 低波轴信息大部分已在模型内，惩罚的边际倾斜把低效方向放大。

- **剂量-反应（登记）**：λ 从 0.25 → 0.50（同列），信号层损失加深（−43.4 → −47.8 bps），

  与主判据失败方向一致；
- **列间对照**：cvar 臂（风险等价口径，已按“越负越危险”取 sign）位移与损害同量级（信号 −31.3 bps、
  重叠 26.4%）⇒ 结论对具体列不敏感，问题在机制本身（rank 空间强倾斜）；
- 位移（Top20 集合重叠 / 换入）：dv050 **19.0% / 16.2 只/日**；cv025 **26.4% / 14.7 只/日**。
