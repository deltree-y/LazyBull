# OOS 行业集中度审计（P0 测量 0）

> 2026-09-21 测量 / 2026-09-22 归档 · 只读诊断（不改代码、不改数据）
> 基准批次 `wf_batch_20260920_151922`（CAGR 23.72% / MaxDD −18.62%，1,700 个收益日）
> 归档产物：`data/reports/oos_p0_20260921/`（逐日明细 + 汇总 + 复跑脚本）

## 1. 问题与背景

方案评审中提出 B2"行业约束实验"（`bt_max_per_industry` 在回测从未启用）。
需要实证回答两个问题：

1. 组合的行业集中度是否显著偏离"随机抽样"基线（选股域使用申万二级行业，100+ 类）？
2. 是否存在"行业集中 → 回撤/大亏"的实证关联？

## 2. 数据与口径

- 持仓：14 折逐日持仓快照（`walk_forward_持仓快照_*`，29,128 行 / 1,700 交易日）。
- 行业：`data/raw/shenwan_industry.parquet`（**当前快照**，无历史版本字段——分类变更
  带来轻微前视，对结构性统计可忽略）。
- 集中度：持仓内部归一化权重；HHI = Σw²；相对集中度 = 实测 HHI ÷ 同持仓数随机基线。
- 随机基线：市场行业分布（全表股票数占比）下等权 iid 抽样，蒙特卡洛 2,000 次/档，
  seed=20260921。**简化模型**（真实权重非等权），只用于量级对照。
- 大亏日：组合日收益 < −2%（61 天，与 2026-09-21 诊断报告一致）；对照用 **t−1 日**
  持仓结构（决定 t 日损益）。
- 置换检验：两组标签随机打乱 10,000 次。
- 校验：平均现金占比 17.58%（与诊断一致）；收益流口径校验见同批《测量 A》。

## 3. 主要结果

### 3.1 集中度的绝对水平（不高）

| 指标 | L1 口径 | L2 口径 |
|---|---:|---:|
| 平均行业数 | 11.2 | 13.7 |
| HHI 均值 | 0.138 | 0.107 |
| 最大行业权重均值 | 23.2% | **18.4%** |
| 前三行业权重均值 | — | 42.8% |
| 最大行业股票数（中位 / p90 / max） | — | **2 / 4 / 6** |

### 3.2 相对随机基线：轻度偏高

- HHI = 基线的 **1.23×**（L1）/ **1.39×**（L2）；最大行业权重 18.4% vs 基线 12.6%。
- ⇒ 信号存在轻微行业倾向，但**不极端**；最集中的 5 天（2019-11）系"仅 8 只持仓"的
  被动集中，非选股群聚。

### 3.3 大亏日对照：无正向关联（关键裁决）

| 检验 | 均值差（大亏日 − 其余） | 置换检验 p |
|---|---:|---:|
| 绝对口径 `prev_hhi_L2` | −0.0074（方向"更分散"） | 0.061 |
| **控制持仓数（相对集中度）** | **+0.0081** | **0.831** |
| 分层 n≥16（61/61 大亏日所在层）· 相对集中度 | +0.0002 | — |

绝对口径的表象差异系**持仓数混淆**（大亏日前持仓平均多 1.1 只，HHI 被分母稀释）；
控制后差异归零。**分档前瞻（按相对集中度三分档）无单调模式。**

### 3.4 附带观察

- 持仓不足期：仅 3.9% 的日子满 20 只、8.1% 不足 16 只；n<16 的 136 天 **0 个大亏日**
  （机制未验证——可能与现金占比高/暴露低有关，不作推断）。
- 行业缺失行 0.55%（未知行业权重均值 0.66%，单日最大 13.4%），不构成结论风险。

## 4. 结论

1. 行业集中度绝对水平不高；相对随机轻度偏高（1.2~1.4×）。
2. **"行业集中 → 回撤升高"不成立**——控制持仓数后逐值无差异；与既有证据一致
   （61/61 大亏日均为市场级下跌）。
3. **处置：B2 关闭**——不再开"行业约束"实验臂。
4. 登记项：**纸面 vs 回测不对称**——纸面 `config.yaml` 启用 `max_per_industry: 5`
   （回测从未启用），列入"传导率审计"清单。

## 5. 已知局限

- 行业映射为当前快照（非逐日历史分类）；随机基线为等权简化模型；窗口重叠为描述性统计。
- 本审计只证伪"集中度→回撤"这一条假设；**不构成**"行业信息无用"的证据
  （如行业动量类信号的其它载体未测）。
