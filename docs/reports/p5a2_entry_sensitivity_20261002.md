## 2. §3.3 爬坡建仓立项门判读素材

- **敏感度宽度**：IQR ≈ 4.6~5.2pp；最差−中位差 B1 4.7pp / B0 6.9pp。
- **对照净值层刻度（F7 定稿 MDE = 12pp）**：起点敏感度宽度**在净值层可检出刻度之下**——
  「何时入场」造成的结局差异小于系统能裁决的最小效应。
- **回撤维度**：入场点对 MaxDD 几乎无影响（中位 = 最差）——持续在场体系下崩盘段必然在窗口内，
  爬坡建仓改变的只是「到达目标暴露的节奏」，躲不开段本身。
- **判读方向（非立项结论）**：立项门要求「实测敏感度宽度 > 阈值才立项」（阈值待 §3.3 预登记写死）；
  以 MDE=12pp 为参照系，实测宽度（≤7pp）大概率不越线 ⇒ 爬坡建仓方向倾向**不立项**。
  **正式判定必须走预登记**（含阈值数值与判据），本报告不替代该程序。
- **主口径声明（F9R B-1，口径自由度在此关闭）**：敏感度宽度的主口径 = **IQR + 最差−中位双口径并引**
  （IQR 4.58/5.15pp、最差−中位 4.7/6.9pp）；**不取全距**——分布右偏长尾由极早期起点贡献、
  有效自由度折级，全距非稳健量。§3.3 爬坡立项门预登记必须写死宽度主口径与阈值数值
  （本报告两口径均 < MDE 12pp；全距口径下结论会反转，故口径必须在预登记前关闭）。

- chain_nav 的 `date` 列为位置索引（无日历日），最差起点以「索引 + split」标注（split5/6 ≈ 2021~2022 回撤段）。
- B1−B0 中位差 +1.74pp 仅登记（政策层已裁决退役，方案 F8；该差值不构成保留依据）。
- 有效自由度 ≈ 折数级（14 折）；IQR/std 为描述性离散度，不作统计裁决。
