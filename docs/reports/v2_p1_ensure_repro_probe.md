## 1. 探测口径的实测约束（方案与现实的差异登记）

方案 §8-P1 原文写「抽 3 个月分区」比对。实测发现：**cs_infer 按设计只滚动保留最新交易日**
（单日快照，纸面链路每次重建，实测仅 `20260702` 一个分区），不存在多月历史分区
⇒ 「抽 3 个月分区比对 cs_train vs cs_infer」在产物层**不可行**。

探针因此分两档：

- **口径 A（本报告，已执行）**：cs_infer 最新日（20260702）vs cs_train 同日逐值比对——
  回答「两条构建路径在同一日的同股同列是否一致」（可复现性的核心证据）。
- **口径 B（登记为 P1 后续任务，机器时间另申请）**：历史区间重放比对——
  在临时数据根上对 3 个月区间跑「ensure 链路重放 vs cs_train 冻结快照」，
  属冻结参照实现的前置（需授权）。

## 2. 口径 A 实测结果（20260702，5158 行交集）

| 维度 | 数值 | 判定 |

## 3. 两类「预期内差异」的归因（登记，非漂移）

### 3.1 截面口径差异（104 列，zscore_*_sz / vol_regime_percentile）

- **现象**：zscore_*_sz 列 100% 行不一致，最大差 ~0.2~2.5（同量级小幅差）；
  vol_regime_percentile 全列不一致（最大差 0.468）。
- **根因**：cs_train 批量构建用「当日**全市场**截面」做 zscore/百分位；cs_infer 单日重建用
  「当日**可得**截面」（ensure 链路的证券域可能略窄）——两者截面边界不同 ⇒ 逐值必差。
- **性质**：这是 **R1-4 已登记的「构建窗口口径漂移」的预期实例**（第三类漂移：构建窗口口径，
  非数据态、非实现 bug）。**不是实现漂移**，比对判据已排除（单列登记）。
- **对 P1 的含义**：单表 features 的构建器必须**冻结截面口径**（全市场统一截面），
  否则 cs_train → panel 回填会携带同一类口径位移；该约束写进 P1 回填的「构建窗口口径冻结」。

### 3.2 运行时派生列（24 列）

- cs_infer 比 cs_train 多 holdertrade / repurchase / top10fh 三族共 24 列——
  **契约设计如此**（三族「运行时派生、不写回 cs_train」）。探针报告单列登记、不进判据。
