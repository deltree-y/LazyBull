## 4. 裁决推理（fallback：结构判据 + 定性证据）

1. **结构判据决定性**：唯一 §4.8 违规组件 + 最高迁移成本，为确定性成本；收益侧量级
   （≈0.5~1.2pp/年）在现行 14 折设计与可得尺子（MDE 12pp）下不可证（F8R-C1 措辞收敛：
   MDE ∝ 1/√n，加折 / 多年台账跨季累积理论可缩——但均不在本期可得范围），无法对冲确定性成本。
2. **卖点在严格口径不成立**：回撤改善经 R-004（在线口径不达标）→ R-007（滞留承载）→
   B0/B1 配对（跨 λ 实现不进判据）三轮压缩；合法承诺域（亏损日幅度）虽有作用，
   但全日净效应 ≈ 0。
3. **纪律价值**：v2 防腐化核心 = 「不可验收的增量不进默认链路」；带唯一例外进新系统会在
   P2a 立坏先例。迁移期是卸下它的唯一零代价窗口（生效时点 = v2 切换日，旧链路不受影响）。
4. **可逆性保留**：退役 ≠ 永别——§4.7 全流程（切换日默认链路移除 + 代码删除 + git tag 留档 +
   本档案），重开条件见 §6。

**裁决：退役。迁移目标 = B0（neutral 无政策臂）。**
