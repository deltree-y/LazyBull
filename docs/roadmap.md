# LazyBull 项目路线图

> 当前版本：v0.98.3  
> 最后更新：2026-08-30

## 项目愿景

打造一个**专注于 A 股价值红利策略**的量化研究、训练、回测与纸面交易框架，支持从本地研究、批量实验、滚动训练到云端/树莓派辅助监控的完整生命周期。

当前项目已经从早期 MVP 进入生产化研究框架阶段：核心数据链路、特征工程、ML 训练、滚动回测、纸面交易、钉钉机器人和 LCD35 辅助展示均已具备可用实现；后续重点转向因子有效性验证、组合与风险管理增强、自动化运维和实盘接口预研。

## 当前实现快照

### 已完成主链路

- [x] TuShare 原始数据下载、基础数据更新与按日期/年度/季度分区 Parquet 存储。
- [x] clean/features 分层构建，支持 120 日预热、单日 ensure 自动补齐、cs_train/cs_infer schema 对齐。
- [x] XGBoost 训练、模型注册、早停、IC/RankIC 评估、滚动训练与多子集集成。
- [x] 回测引擎支持 T0/T1 执行链路、涨跌停/停牌约束、成交额过滤、动态 Top-N、Kelly 仓位、收益明细与执行归因。
- [x] 纸面交易支持 T0 信号、T1 执行、状态持久化、实时行情、分批调仓、失败补位和持仓展示。
- [x] 钉钉机器人复用纸面交易 runtime/reporting，支持交易、持仓、模型与账户查询。

## 风险与挑战

### 技术风险
- 高积分接口字段语义、分页上限、修订版本和历史覆盖状态容易造成 PIT 偏差。
- 大截面、多因子、多年窗口构建可能出现内存和耗时瓶颈。
- 训练、回测、纸面交易三条链路的 schema 与配置漂移会放大实验误差。

### 策略风险
- 价值红利策略可能在成长风格或低利率切换阶段阶段性失效。
- 新增因子即使 IC 有效，也可能在成交约束、持仓集中度或换手成本后失效。
- 参数搜索过宽会带来过拟合和验证集复用风险。

### 运维风险
- 自动补齐链路依赖外部 API，需处理限频、空响应、字段缺失和部分失败。
- 纸面交易状态文件与远端展示链路需要备份、校验和故障恢复。
- 实盘接口必须有人工确认、异常停机和完整审计日志，不能直接从纸面交易无缝放大。

### 缓解措施
- 所有公告型/版本化因子坚持 PIT、schema 哨兵和 fail-fast 校验。
- 生产默认因子必须经过 WF、缺失率、稳定性和执行转化损耗验证。
- 回测/纸面共享 TradingConfig、信号门控和交易归因语义。
- 定期运行窄口径回归测试和关键链路 smoke test。
- 重要数据和模型版本保留可回滚快照。
