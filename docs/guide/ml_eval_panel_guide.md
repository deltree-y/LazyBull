# ML 评估面板使用指南

## 概述

ML 评估面板是 LazyBull 框架提供的一个功能，用于评估机器学习选股信号的预测质量。它在回测运行时按日评估 MLSignal 的截面排序能力，并输出 CSV 文件便于分析和对比不同实验配置。

## 为什么需要评估面板？

### 传统回测的局限

传统回测主要关注"策略收益"（如年化收益、夏普比率、最大回撤），但这些指标：
- 受交易成本、滑点、止损等执行细节影响
- 无法直接反映"预测本身的质量"
- 难以区分是模型好还是交易策略好

### 评估面板的价值

评估面板直接评估"预测分数 vs 真实收益"的关系，提供：
- **RankIC**：预测排序与真实收益排序的相关性（Spearman）
- **TopK 收益**：预测最高的 K 只股票的平均真实收益
- **分组收益**：按预测分数分组后，各组的平均真实收益
- **多空收益**：Top组 - Bottom组 的收益差

这些指标能够：
- 快速判断模型是否有预测能力
- 对比不同 horizon（5日/10日/20日）的预测效果
- 识别模型失效的时间段
- 优化选股参数（TopN、分组数等）

## 快速开始

### 1. 基本使用

运行回测时，评估面板默认开启：

```bash
python scripts/run_ml_backtest.py \
    --start-date 20230101 \
    --end-date 20231231 \
    --top-n 30
```

会自动生成三个评估 CSV 文件（存放在 `data/reports/` 目录）：
- `ml_backtest_eval_daily.csv`：日度评估指标
- `ml_backtest_eval_groups.csv`：分组收益明细
- `ml_backtest_eval_summary.csv`：汇总指标

### 2. 查看评估结果

#### 日度评估 CSV

打开 `ml_backtest_eval_daily.csv`，可以看到每天的评估指标：

| 交易日期 | 样本数 | RankIC | TopK平均收益 | Top组平均收益 | Bottom组平均收益 | 多空收益 |
|---------|--------|--------|-------------|--------------|----------------|---------|
| 20230103 | 3500 | 0.125 | 0.0285 | 0.0312 | -0.0089 | 0.0401 |
| 20230104 | 3520 | 0.098 | 0.0210 | 0.0245 | -0.0051 | 0.0296 |
| ... | ... | ... | ... | ... | ... | ... |

**如何解读**：
- **RankIC > 0**：预测与真实收益正相关（越大越好，通常 0.05-0.15 已经不错）
- **RankIC < 0**：预测与真实收益负相关（说明预测失效或反转）
- **TopK平均收益 > 0**：预测最高的股票确实有正收益
- **多空收益 > 0**：做多 Top 组、做空 Bottom 组能盈利（理想情况）

#### 分组收益明细 CSV

打开 `ml_backtest_eval_groups.csv`，可以看到每天各组的收益：

| 交易日期 | 组号 | 组内股票数 | 组内平均真实收益 | 组内平均预测分数 |
|---------|-----|-----------|----------------|----------------|
| 20230103 | 1 | 350 | 0.0312 | 0.0856 |
| 20230103 | 2 | 350 | 0.0198 | 0.0623 |
| 20230103 | 3 | 350 | 0.0102 | 0.0445 |
| ... | ... | ... | ... | ... |
| 20230103 | 10 | 350 | -0.0089 | -0.0123 |

**如何解读**：
- **理想情况**：组号越小（分数越高），收益越高 → 单调递减
- **反转效应**：组号小的反而收益低 → 模型失效或市场风格切换
- **中间组收益最高**：可能存在非线性关系，需要进一步分析

#### 汇总 CSV

打开 `ml_backtest_eval_summary.csv`，可以看到整个回测期的汇总指标：

| 回测时间 | 开始日期 | 结束日期 | 标签列 | RankIC均值 | RankIC标准差 | RankIC_IR | TopK平均收益 | 多空平均收益 |
|---------|---------|---------|--------|----------|------------|----------|-------------|------------|
| 2024-02-12 10:30:00 | 20230101 | 20231231 | y_ret_5 | 0.108 | 0.082 | 1.32 | 0.0245 | 0.0335 |

**如何解读**：
- **RankIC均值**：平均预测能力（> 0.05 通常可用，> 0.10 很好）
- **RankIC_IR**：IC 信息比率（均值/标准差，> 1.0 说明 IC 稳定）
- **TopK平均收益**：选出的 TopK 股票的平均收益（越高越好）
- **多空平均收益**：多空组合的平均收益（反映预测的区分度）

### 3. 禁用评估面板

如果不需要评估面板（例如只关心回测收益），可以禁用：

```bash
python scripts/run_ml_backtest.py \
    --start-date 20230101 \
    --end-date 20231231 \
    --no-export-eval
```

## 高级用法

### 对比不同 horizon

不同预测窗口（5日/10日/20日）的预测难度不同，可以分别评估：

```bash
# 评估 5 日预测
python scripts/run_ml_backtest.py \
    --start-date 20230101 --end-date 20231231 \
    --label y_ret_5 --rebalance-freq 5 \
    --output-name exp_5d

# 评估 10 日预测
python scripts/run_ml_backtest.py \
    --start-date 20230101 --end-date 20231231 \
    --label y_ret_10 --rebalance-freq 10 \
    --output-name exp_10d

# 评估 20 日预测
python scripts/run_ml_backtest.py \
    --start-date 20230101 --end-date 20231231 \
    --label y_ret_20 --rebalance-freq 20 \
    --output-name exp_20d
```

然后对比三个实验的 `*_eval_summary.csv`：

| 实验 | RankIC均值 | RankIC_IR | TopK平均收益 | 多空平均收益 |
|-----|----------|----------|-------------|------------|
| 5日 | 0.108 | 1.32 | 0.0245 | 0.0335 |
| 10日 | 0.095 | 1.18 | 0.0412 | 0.0598 |
| 20日 | 0.082 | 1.05 | 0.0685 | 0.0892 |

**常见结论**：
- **短期（5日）RankIC 更高**：短期预测相对容易
- **长期（20日）收益更高**：长期收益累积更多
- **需要权衡**：高 IC 但低收益 vs 低 IC 但高收益

### 调整分组数

默认分 10 组，可以调整为更细粒度（如 20 组）：

```bash
python scripts/run_ml_backtest.py \
    --start-date 20230101 --end-date 20231231 \
    --eval-groups 20
```

**建议**：
- **10 组**：适合大多数情况，样本量充足
- **20 组**：适合股票池很大（> 2000 只）的情况
- **5 组**：适合股票池较小（< 500 只）的情况

### 调整 TopK

TopK 指标默认使用 `--top-n`，但也可以单独指定：

```bash
python scripts/run_ml_backtest.py \
    --start-date 20230101 --end-date 20231231 \
    --top-n 30 \
    --eval-topk 50
```

这样回测时选 30 只股票，但评估时观察 Top 50 的收益。

**用途**：
- 评估如果扩大选股范围，收益会如何变化
- 检查 Top 30 vs Top 50 的收益差异，决定是否需要调整 TopN

### 批量实验对比

可以运行多个实验，所有结果会累加到同一个 `*_eval_summary.csv`：

```bash
# 实验1：TopN=20
python scripts/run_ml_backtest.py \
    --start-date 20230101 --end-date 20231231 \
    --top-n 20 --output-name exp_top20

# 实验2：TopN=30
python scripts/run_ml_backtest.py \
    --start-date 20230101 --end-date 20231231 \
    --top-n 30 --output-name exp_top30

# 实验3：TopN=50
python scripts/run_ml_backtest.py \
    --start-date 20230101 --end-date 20231231 \
    --top-n 50 --output-name exp_top50
```

然后查看 `data/reports/*_eval_summary.csv`，会有三行记录，可以对比：

| TopN | RankIC均值 | RankIC_IR | TopK平均收益 | 多空平均收益 |
|------|----------|----------|-------------|------------|
| 20 | 0.108 | 1.32 | 0.0312 | 0.0398 |
| 30 | 0.108 | 1.32 | 0.0285 | 0.0365 |
| 50 | 0.108 | 1.32 | 0.0245 | 0.0335 |

**常见结论**：
- RankIC 不随 TopN 变化（因为是全市场排序）
- TopK 收益随 TopN 增大而降低（选股更多，边际收益递减）

## 评估指标详解

### RankIC（Rank Information Coefficient）

**定义**：预测分数与真实收益的 Spearman 秩相关系数

**计算方法**：
1. 对预测分数排序，得到排名 R_pred
2. 对真实收益排序，得到排名 R_real
3. 计算 R_pred 和 R_real 的 Pearson 相关系数

**取值范围**：[-1, 1]
- **1.0**：完美正相关（预测完全准确）
- **0.0**：无相关（预测无效）
- **-1.0**：完美负相关（预测完全反向）

**行业标准**：
- **< 0.02**：几乎无预测能力
- **0.02 - 0.05**：弱预测能力，可能勉强可用
- **0.05 - 0.10**：中等预测能力，可用于实盘
- **> 0.10**：强预测能力，优秀的因子/模型

### RankIC IR（Information Ratio）

**定义**：RankIC 的信息比率 = RankIC均值 / RankIC标准差

**意义**：
- 衡量 IC 的稳定性
- IR 越高，说明 IC 越稳定，模型鲁棒性越好

**行业标准**：
- **< 0.5**：IC 波动大，不稳定
- **0.5 - 1.0**：中等稳定性
- **> 1.0**：高稳定性，优秀

### TopK 平均收益

**定义**：预测分数最高的 K 只股票的平均真实收益（未来 N 日收益）

**意义**：
- 直接反映"选出的股票"的质量
- 如果 TopK 收益为负，说明选股失败

**注意**：
- TopK 收益不等于策略收益（因为没考虑交易成本、滑点等）
- 但 TopK 收益高，策略收益通常也会高

### 多空收益

**定义**：Top组平均收益 - Bottom组平均收益

**意义**：
- 反映预测的"区分度"
- 如果多空收益为正，说明模型能区分好股票和差股票
- 多空收益越大，模型的选股能力越强

**策略应用**：
- 如果多空收益稳定为正，可以考虑多空策略（做多 Top 组，做空 Bottom 组）
- 但需要注意卖空成本、融券可得性等实际约束

## 常见问题

### Q1: 为什么 RankIC 很低但回测收益很高？

**可能原因**：
1. **交易成本低**：即使选股能力一般，低成本也能带来收益
2. **市场行情好**：牛市中随机选股也能盈利
3. **运气好**：样本外表现未必能复现

**建议**：
- 关注 RankIC 和 IR，不要只看回测收益
- 如果 RankIC < 0.05，建议重新训练模型

### Q2: 为什么 RankIC 很高但回测收益很低？

**可能原因**：
1. **交易成本高**：频繁调仓导致成本吃掉利润
2. **滑点大**：实际成交价与预期价格偏差大
3. **执行问题**：买入时机、卖出时机不合理

**建议**：
- 优化交易策略（降低调仓频率、改进买卖时机）
- 降低交易成本（选择低佣金券商、减少换手）

### Q3: 为什么某些日期没有评估数据？

**可能原因**：
1. **没有特征数据**：该日期没有 `cs_train/*.parquet` 文件
2. **所有样本的 label 缺失**：例如最后几个交易日，未来收益无法计算
3. **股票池为空**：该日期没有符合条件的股票

**解决方法**：
- 检查 `data/features/cs_train/` 目录是否有对应日期的文件
- 回测结束日期不要太接近数据截止日期（至少留出 N 天的 buffer）

### Q4: 评估面板会影响回测性能吗？

**影响较小**：
- 评估过程与回测并行，不会阻塞回测
- 主要开销是遍历所有交易日和计算 RankIC
- 对于长周期回测（> 1 年），可能增加 10-30% 的运行时间

**如果需要极致性能**：
- 使用 `--no-export-eval` 禁用评估面板
- 先快速回测，再单独运行评估（未来可能支持）

### Q5: 如何在 Excel 中分析评估结果？

**步骤**：
1. 用 Excel 打开 `*_eval_daily.csv`（utf-8-sig 编码，直接打开即可）
2. 插入数据透视表或图表
3. 常见分析：
   - 绘制 RankIC 时序图（折线图）
   - 计算 RankIC 的移动平均（识别趋势）
   - 绘制分组收益曲线（柱状图）
   - 计算 IC > 0 的天数占比（胜率）

**Python 分析示例**：

```python
import pandas as pd
import matplotlib.pyplot as plt

# 读取日度评估数据
df = pd.read_csv('data/reports/ml_backtest_eval_daily.csv')

# 绘制 RankIC 时序图
plt.figure(figsize=(12, 6))
plt.plot(df['交易日期'], df['RankIC'])
plt.axhline(y=0, color='r', linestyle='--')
plt.title('RankIC 时序图')
plt.xlabel('日期')
plt.ylabel('RankIC')
plt.xticks(rotation=45)
plt.tight_layout()
plt.savefig('rank_ic_time_series.png')

# 计算统计指标
print(f"RankIC 均值: {df['RankIC'].mean():.4f}")
print(f"RankIC 标准差: {df['RankIC'].std():.4f}")
print(f"IC > 0 的天数占比: {(df['RankIC'] > 0).mean():.2%}")
```

## 总结

ML 评估面板是 LazyBull 框架的重要功能，它能够：
- ✅ 直接评估模型的预测质量（RankIC、TopK 收益等）
- ✅ 快速对比不同实验配置（horizon、TopN、模型版本等）
- ✅ 识别模型失效的时间段
- ✅ 提供可量化的选股能力指标

**建议使用场景**：
1. **模型调优**：对比不同特征组合、模型参数的预测效果
2. **参数选择**：确定最优的 horizon、TopN、调仓频率等
3. **模型监控**：定期评估模型的 IC，及时发现失效
4. **策略开发**：基于评估结果设计更优的交易策略
