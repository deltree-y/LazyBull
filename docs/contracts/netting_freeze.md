## 1. 定位与冻结承诺

- 合并与净额化规则 = **无开关的确定性算法**。本文件冻结后，任何修改（含参数化请求）必须走预登记，并升级本文档版本行。
- 冲突优先级（从高到低，写死）：**费用最小化 > 净额化 > 集中度约束 > 目标跟踪**。
- **禁止候选域互斥 / 先占规则**——把耦合下沉到信号层、用反事实归因污染独立验收的形态一律禁止（R1-5 对抗验证结论）。
- 立法依据：方案 §3.2（运行形态 / lot 批次模型）、§4.9（跨袖资金调度）、R1-5（分层语义合成结论）。

## 2. 分层语义（核心条文）

### A 区 · 已验证语义（单袖退化，P2a/P2b 对账可验）

- **A1 直通退化**：MVP 仅袖子 A 时，合并器退化为**直通**——目标权重原样透传，不新增任何判定分支；开启合并器前后与现引擎**逐位一致**（P2b 验收口径）。
- **A2 调度退化**：单袖无借无还，§4.9 的占用条目恒为空，三恒等式（§4）退化为单袖 trivial 等式。
- **A3 lot 语义沿用既有契约**：回补不重置买入日（同一 lot 延续）、补齐买入算新持仓（新 lot）——与 A3 建仓折扣回补契约逐字兼容。

### B 区 · 设计意图（P6.5 可做合成构造对账，但不得据此转正；P7 历史多臂实测复核，F24-A6）

- **B1 抵消部分 = 虚拟账本内部转账，无条件完成**：跨袖同股反向指令（A 卖 X / B 买 X）的重合股数**不生成市场指令**，不受涨跌停影响；双方虚拟账本按 §5 定价规则各自入账。
  "无条件"的边界：当日有内核成交价（T+1 开盘价口径）即完成；**停牌日无价格 ⇒ 该笔转账顺延至首个有价格的交易日**（不编造价格）。
- **B2 仅净额部分生成市场指令**：净额 = 各袖同股指令代数和；净额部分按《执行时点契约》判定（T+1 开盘价、涨跌停 / 停牌顺延），与单袖时代同一口径。
- **B3 合并顺序写死**：目标权重叠加 → 集中度上限截断（§3.3 硬约束优先于一切）→ 整手取整 → 资金不足时按 §4.9 借用规则分配下单额度。
- **B4 退出不被剥夺**：A 的卖出在虚拟账本上**无条件完成**（不依赖 B 的买入是否被涨停挡住）——这是分层语义相对朴素净额实现（整单互抵）的根本区别，也是"独立存活验收"的会计前提。

**P6.5 合成对账边界（F25 草案，用户 Q12/Q13/Q22）**：

- P6.5 可为三件套构造 S1/S4/S6 合成场景，并验证本文件 I1~I3、lot 与费用算法；**构造通过不等于 B1~B4 行为转正**，B 区仍须 P7 历史多臂复核 + 用户显式裁决。
- 停牌/无价输入在 P6.5 采用 **fail-fast 拒绝**，不建立跨日顺延义务；B1 的“顺延至首个有价格交易日”仍是 P7 设计意图，不因 P6.5 构造而改写。
- S2/S3 本阶段显式拒绝；S4 部分成交后的剩余意图**日终作废、次日重新决策**，不设跨日顺延；S5 本阶段显式拒绝，其独立费用口径不与 S4 公式混用。
- P6.5 证据必须标识“合成算法对账，不与生产物理账逐 lot 对账，不构成多袖生产结论”。

## 3. 状态机表（同一股票 × 多袖子 × 指令方向）

| # | 袖子 i 指令 | 袖子 j 指令 | 物理市场指令 | 虚拟账本动作 |
|---|---|---|---|---|
| S1 | 卖 s | 买 b（s = b） | **无** | 抵消 s 股：i 减持 s / j 增持 s，内部转账价入账（§5），双方零费用 |
| S2 | 卖 s | 买 b（s > b） | 净卖 s−b（涨跌停判定） | 抵消 b 股同 S1；净卖部分归 i，按实际成交入账，未成交顺延 |
| S3 | 卖 s | 买 b（s < b） | 净买 b−s（涨跌停判定） | 抵消 s 股同 S1；净买部分归 j，按实际成交入账，未成交顺延 |
| S4 | 买 b_i | 买 b_j | 合并买 b_i+b_j | 按 §5 同向合并分摊规则各自入账 |
| S5 | 卖 s_i | 卖 s_j | 合并卖 s_i+s_j | 各袖按自身卖出量入账（FIFO 消耗各自 lot） |
| S6 | 单袖指令 | 无 | 仅真正单袖账户原样；多袖账户由 F13 恢复物理全量目标 | 单袖语义（= A 区直通）；多袖账户即使本批只一袖发单，也必须计入其他袖当前虚拟持仓，不得直接透传 `target_shares` |
| S7 | 持有到期 | 持有 / 任意 | 由净额结果决定 | 各袖 lot 独立到期；到期卖出指令与其他袖指令进入同一净额化流程 |

**公司行为拆分（分红 / 送股 / 拆股）**：物理账户收到现金分红 ⇒ 按**除息日（权益登记口径）**登记各袖应收（F3，P0 评审 3-D——避免到账日口径下除息后已调仓的袖子分到不属于它的分红），到账日兑付；送股 / 拆股同理以除权日持仓为准（新增股数并入原 lot，不重置买入日）。

**净额未成交的归属**：S2/S3 中净额部分未成交（涨跌停 / 停牌）时，顺延义务与顺延资格**全部归属净额方向的袖子**；被抵消的另一袖不受影响（其虚拟账本已完成）。

## 4. 虚拟账本三恒等式（验收口径，F25 草案细化）

- **I1 现金**：Σ_i 虚拟现金_i ≡ 物理现金（§4.9 资金占用的虚拟条目在现金项内两两对消后成立）。P6.5 无借用子集还要求**每个袖** `borrowed_credit == 0`、费用后自有虚拟现金非负；占用合计为 0 不能替代逐袖守卫。
- **I2 持仓**：∀ 股票 x：Σ_i 虚拟持仓_i(x) ≡ 物理持仓(x)，且在 **lot 级**成立。P6.5 比较前先按 `(ts_code, 物理来源 lot_id)` 汇总整数股数，再与显式物理 lot 伴随视图逐键比较；虚拟侧不得出现物理不存在的来源键，**不比较 lot 条目数**。P6.5 右值是合成伴随视图，不等于生产物理账已 lot 化；虚拟取得批次另以 `(sleeve_id, 虚拟取得 lot_id)` 唯一。
- **I3 NAV**：Σ_i 虚拟 NAV_i_contrib ≡ 物理 NAV。P6.5 的组合贡献 NAV 统一用 `total_value_i / 物理账户初始资金`，所有袖共用同日同价源；各袖以自身初始资金为分母的独立 NAV 不参与 I3，归 P7。自拆 G4 不比较逐袖贡献 NAV 和，而是先合并各袖货币总值，再单次派生合并 NAV 与单袖逐位比较。

**容差**：I1 货币绝对差 ≤ `1e-6`，I2 整股零差，I3 直接 NAV 绝对差 ≤ `1e-6`；货币总值和以同容差辅证。该容差来自既有 `Position` 货币聚合与架构归一净值口径（用户 Q5=B）；runs 批次内部 `1e-3/1e-6` 不用于臂间逐位门。

**验收**：三恒等式**从 P6.5 第一天存在并进 CI**，逐日成立；任何一日任一恒等式破缺 ⇒ **报错停止**（不是告警）。
它是所有跨袖结论（独立夏普、相关性、资金利用率）的会计地基——地基测试晚于机制实现 = v1 的病在 v2 重演。

## 5. lot 批次模型与定价 / 费用归属

- **lot 定义**：`物理来源 lot = (物理来源 lot_id, 买入日, 股数, 买入价)`。每次买入（含补齐买入）产生新物理来源 lot；回补不重置买入日（A3 先例）；公司行为新增股数并入原 lot。内部转账保留物理来源 lot 谱系，同时在虚拟账记录 `(sleeve_id, 虚拟取得 lot_id, 取得日, 取得价)`；虚拟经济成本与物理原始成本分开保存，I2 不以成本相等作为来源判据（F25 / Q14=A）。
- **卖出消耗顺序**：FIFO——**最早买入日的 lot 优先消耗**；净额化到期归属同样以最早买入的虚拟份额为准（lot 级记账是三恒等式归属拆分的前提）。
- **内部转账定价**：当日 **T+1 开盘价口径**（与物理净额指令同一价格源）；转账部分**双方零费用**。P6.5 无价时拒绝，不顺延。
- **费用归属（抵消情形 S1~S3）**：只有净额部分产生物理费用，**全部归属净额方向的袖子**；抵消部分双方零费用。
  会计后果：抵消双方各自按「视同独立成交」记录价格、但省掉各自本应付出的费用——费用节省由促成抵消的两袖各自留存，不设公共池。
  （恒等式自洽性：Σ 虚拟现金变动 = 净额成交额 ± 净额费用 ≡ 物理现金变动。）
- **同向合并分摊规则（F3 + F25 草案，Q13=A / Q18=A）**：
  - **物理与虚拟单位不同**：物理市场订单以 100 股整手为单位；虚拟账分摊以 **1 股**为单位。理论分摊 `r_i = Q×原始增量_i/Σ原始增量`，先逐袖向下取整；余数按 `(原始增量降序, sleeve_id 字典序)` 逐股分配，且固定满足 `0 ≤ 分得股数_i ≤ 原始增量_i`。容量已满跳到下一袖；完整一轮后仍有余数即拒绝，禁止超目标分配。例：三袖各 167 股、物理成交 500 股 ⇒ `(167,167,166)`。
  - **全零成交短路（C65-03）**：`Σa=0` 且 `F=0` 时返回全零费用，不调用成本模型、不创建 lot、不改变现金，剩余意图按 Q22 日终作废并保留零成交证据；`Σa=0` 且 `F≠0` 直接拒绝。该短路先于终端袖选择。
  - **费用分配完整公式**：对每袖原始意图金额 `q_i`、实际分得金额 `a_i`；`a_i=0 ⇒ c_i=0`，不得调用最低佣金（`calculate_buy_cost(0)=5`）。独立费用按实际分得金额计算 `c_i=calculate_buy_cost(a_i)`；物理总费用 `F`；总节省 `S=max(Σc_i−F,0)`。
  - **受益顺序**：按 `(q_i 升序, sleeve_id 字典序升序)`。按此顺序做非负瀑布 `s_i=min(c_i, remaining)`、预备费用 `f'_i=c_i−s_i`。当节省超过最小袖独立费用时，余下节省依次归下一较小意图袖，避免负费用。
  - **终端浮点残差**：取该顺序中最后一个 `a_i>0` 的袖为终端袖，其他袖固定为 `f'_i`，终端费用 `f_t=F−Σothers`，统一 float64 从左到右；若 `Σf_i≠F`，允许一次 `f_t += F−Σf_i` 后复算。仍不等、终端为负或零份额收费即拒绝；不得把余数只登记为游离项。
  - **异常分支**：若 `F>Σc_i`，先按 `F×a_i/Σa` 比例分摊再执行终端残差闭合；`Σa=0 且 F≠0` 直接报错。货币不按分舍入。
  - **恒等式校验**：Σ 各袖最终费用 ≡ 物理实际费用（终态精确相等）；股数、费用和虚拟现金/lot 成本必须使用同一最终向量。
  - **S5 本阶段边界**：P6.5 不实现 S5，遇到同向卖出显式拒绝；S5 独立入账与物理费用/I1 的关系仍归 P7 历史多臂复核，不得套用本 S4 公式。
  - 同向卖出（S5）在 B 区的最终设计仍待 P7 复核；**P6.5 只覆盖 S4 合并买入**。
- **单袖退化**：无抵消、无合并分摊，lot 语义与现引擎逐位一致（A 区可验）。

### 5.1 抵消红利与独立评审口径（F3，P0 评审 3-B，拍板）

- **抵消红利**（省掉的佣金 + 印花税）直接进入两袖虚拟账本 ⇒ 独立存活判据的虚拟收益流包含「只在有对手袖时存在」的收益——两个袖子会各自把同一份耦合红利计入独立夏普（组合层加总无碍，**独立验收口径被系统性抬升**）。
- **裁决（拍板）**：**双口径并列**——虚拟账本把「净额化节省」单列科目（可分解字段）；独立评审**默认不含节省**口径，「含节省」作敏感性并列展示；P7 历史多臂指标补「抵消红利规模及其对独立评审的敏感性」。

### 5.2 归还死局兜底（F3，P0 评审 3-C，拍板）

- 三约束互锁的死局：被借方需要时「必须 T+1 归还」+ 归还手段① 放弃新下单（借入方当期无新下单计划则腾不出钱）+ ② 被动卖出默认禁止 + ③ 禁止滚动拖欠 ⇒ 「借入方满仓 + 无新下单」场景下**无合法归还手段**。
- **裁决（拍板）**：明示**传导链**——归还失败 ⇒ 被借方下单延迟排队（进入下一交易日重试，沿 T0/T1 顺延语义）+ 告警 + 台账登记；**不开放被动卖出活口**（与 §4.9 v1.10 最严形态一致）。
- P7 三连指标补「**借期被召回频率**」（决定快袖资金可用性的稳定度）。

## 6. 构造性对账三件套（验收测试，F25 草案细化）

1. **零换手**：A 卖 X 100 股 + B 买 X 100 股（等量），内部转账价 12、物理现金 100,000、股数 400 ⇒ 物理成交 = 0、物理费用 = 0；虚拟贡献 NAV A=0.548、B=0.500、Σ=1.048=物理 NAV（I3 按 `1e-6`）；来源 lot 汇总后 I2 精确成立。无价/停牌输入拒绝且不建立顺延。
2. **分摊守恒**：N 袖同股同向买入，物理成交 200 股、金额 2,000、费用 5；A/B 意图 100/300 股 ⇒ 分得 50/150，费用按 F25 公式为 0/5，Σ费用=5；同时覆盖三袖 `(0,0,5)`、同额字典序、零成交不收费、q/a 排序区分、167/167/167→167/167/166 和输入置换。**全零成交且 F=0**必须返回全零费用且不建 lot；全零成交且 F≠0 必须拒绝。
3. **自拆一致**：A 自拆两个虚拟子袖（固定 0.5/0.5 同一信号流）⇒ 订单级全链物理结果与单袖**经济工件逐位一致**。I3 的逐袖贡献 NAV 和按 `1e-6` 判定；G4 先合并总值再单次派生 NAV 后按位比较，不能把前者当后者。

三件套全部通过是 P6.5 的验收闸门；其中第 3 件同时是 A 区语义的强检验。通过不把 B 区转为 A 区，也不构成多袖生产结论。另须执行 F13 的多袖账户单袖发单、目标/配额校验和缺上下文拒绝用例。

## 7. 与跨袖资金调度（§4.9）的正交关系

- 净额化发生在**物理指令层**（看合并后的物理买卖）；资金借用只影响**各袖虚拟账本的下单额度**——两者正交，禁止互相作为输入。
- 借用产生的虚拟"占用"条目在 I1 的现金项内两两对消，不改变三恒等式口径。
- 借用禁止突破 §3.3 硬约束（单袖最大持仓数 / 单股集中度上限优先于借用）。- **归还优先级（F2，方案 §4.9 v1.10 修订）**：归还 = 借入方**放弃自身新下单**（只压下单额度、不动存量持仓）；**被动卖出现有持仓默认禁止**（`OrderReason` 无对应枚举，实现侧不存在该路径；未来确需须先登记枚举 + 预登记）。被动卖出会污染借入方的独立存活评审口径，故不作为默认机制。

## P7 机械复核适用注记（F26，2026-11-11 生效）

- **S5 实际费用分摊（Q3=A）**：`f_i = F·a_i/A`，终端袖取 `(a_i 降序, sleeve_id 升序)` 首个
  `a_i>0` 者并一次闭合；实际费用非负、`Σf_i = F`；`A=0 且 F=0` 全零、`A=0 且 F≠0` 拒绝；
  独立费用按 `(sleeve, 实际成交日, ts_code, 方向)` 聚合后计算一次，跨日残差逐日计费；
  有符号节省 `s_i = c_i − f_i` 允许为负，`F>Σc` 照常分摊并报告。
- **成交价与估值价分离**：成交只认真实 T+1 开盘价，无价顺延（禁止回退）；估值用
  「当日价 → 最后已知价 → 买入价」解析链并逐股记录 `price_date/price_source`；
  **缓存估值不得完成 B1 内部转账**。
- **授权与配额**：`R_i = max(0, ρ_i·G_i − MV_hold_i)`，`(ρ_V20, ρ_V10) = (0.7, 0.3)`；
  `A^H_i = max{a ≤ min(D_i,R_i): a+Fee(a) ≤ cash_open_i}`、`A^S_i(L)` 同式加 `L`；
  转账后 `cash_i = cash_open_i + L_i`、`credit_i = credit_outstanding_i + L_i`（出借方为负）；
  禁止 `cash_open+credit_outstanding` 或 `cash+credit` 双重背书；日内顺序 =
  预净额计划（零副作用）→ 授权 → 最终净额 → 仅净市场卖出 → 内部转账与净买入 → 一次结算。
- **借用态恒等式**：`Σ_i cash_i ≡ 物理现金` 且 `Σ_i credit_i = 0`（另验本金逐笔对消）；
  I3 允许有符号贡献，仅要求 `E_i` 与物理总值有限、物理初资 > 0；`E_i ≤ 0` 记
  `nonpositive_equity`：禁新增买入与 credit、不被动卖出，聚合 I1/I3 继续逐日审计。
- **覆盖与指标**：自然必达项零观测记 `not_observed/incomplete`，不得改写为 pass；
  ΔŪ 为 cap-binding 构造配额路径的总路径占用差，不读作收益/容量结论；
  S1/S2/S3 反向量与 S4/S5 同向量**分字段计数**，禁止混报。
