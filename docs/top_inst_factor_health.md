## 2. 数据层契约（下载与存储）

| 项 | 实测结论 |
|---|---|
| 存储 | `data/raw/top_inst/YYYY-12-31.parquet`（按 `trade_date` 年分区；单年最大 30.2 万行） |
| 抓取协议 | 逐交易日请求；**单页 `limit=2000` + `offset` 翻页读到空**（实测单日峰值 4,559 行 > 2000，不翻页必丢） |
| 去重 | 全字段 `drop_duplicates`（全字段重复率 0） |
| 下载用时 | 15 年全量 ≈ 21.6 分钟（16 并发） |
| PIT | T 日盘后披露 → 特征日 T 可用、T+1 执行（无前视） |

**工程教训（已修）**：v1 下载脚本"全量拉取 → 最后统一落盘"（全内存），终端中断导致 20 分钟数据全部丢失；
v2 改为**按年分块 + 每年立即写盘 + 断点续传**（跳过已存在年文件），中断损失窗口 ≤ 1 年。
→ 登记为新增数据集下载的默认工程模式。

## 3. 数据质量画像（三类结构性问题，清洗算法由样例+全库验证）

### 3.1 行结构 = 「席位 × side × reason」笛卡尔展开

同一席位的同一笔数据会**重复出现数十倍**：多个上榜原因（reason）各一行、side=0/1 各一行、
且同一榜单存在**新旧两种文本格式**（如"涨幅偏离值达7%的证券" vs "日涨幅偏离值达到7%的前五只证券"）成对出现。
键 `(ts_code, trade_date, exalter, side)` 重复率：2012=13% → 2019=56% → 2024=30%。
**禁止按行求和**（会成倍放大）。

### 3.2 `buy`/`sell` 列互换（数据源侧缺陷，`net_buy` 是可靠锚）

判定：`|sell − buy − net_buy| < 1 且 |buy − sell − net_buy| ≥ 1` → 该行 buy/sell 互换。
实测需修正行占比：2013–2018 年 **30%~75%**；2019 年 30%；2020 年后 0%。
典型：`buy=588万 / sell=851万 / net_buy=+263万`（自相矛盾）→ 互换后自洽。
⇒ **`net_buy` 列在所有年份与所有格式行中一致可信**。

### 3.3 side 语义（修正后自洽）

`side=0` = 买入榜席位（修正后净买为正）；`side=1` = 卖出榜席位（修正后净卖为负）。
（未修正时 2014 年样例看似反号，互换修正后方向全部自洽。）

### 3.4 清洗算法（四步，已全库验证）

1. **列错位修正**（按 3.2 判定互换）；
2. **去重**：键 `(ts_code, trade_date, exalter, side, 修正后 buy, sell, net_buy)`
   （同席位同金额同方向 = 同一事实的重复披露）；
3. **单日榜优先**：剔除 reason 含"连续/累计"行（N 日窗口口径，禁止与单日混用；对齐 `factors/lhb.py` 先例）；
   若某股票日无单日榜行则保留连续榜行（不误标未上榜）；
4. 聚合到（股票 × 日）：机构专用（`exalter == "机构专用"` 精确匹配）行 `sum`（多机构分列披露）。

清洗效果：2,686,011 → 1,925,675 行（保留 71.7%）；
**对照验证**（清洗后 `sum(net_buy)` vs `top_list` 股票级 `net_amount`，9,000~16,000 股票日/年）：
中位相对误差 **0.0%**，<5% 误差占比 62%~86%（残余差异来自 top_list 只统计前 5 主方向席位，两源定义本就不同）。

## 4. 因子与体检明细

因子（均 ÷ 流通市值，当日口径；滚动窗口 20 交易日）：
`ti_inst_net_ratio` / `ti_inst_buy_ratio` / `ti_inst_sell_ratio` / `ti_inst_net_sum_20` / `ti_inst_days_20`。

样本：cs_train 抽样 381 天（2015~2025 每年约 30 天），1,356,020 行。

### 4.3 事件域检验（有机构记录的 1,127 股票日）

事件域平均次 20 日收益 **−3.83%**（机构参与股票整体跑输——与"上榜=炒作=反转"一致）；
机构净买强度五分位收益 −5.7%/−4.0%/−2.4%/−5.3%/−1.8% ⇒ **无单调排序能力**。

## 5. 再启条件（日后若要重开）

仅当满足以下之一且**重新预登记**后可重试：
1. **新载体**：席位身份结构（顶级游资/机构 vs 游资分化）——需要稳定席位分类依据（当前无公开可靠名录，主观性风险高）；
2. **新标签目标域**：事件域内短窗口（5/10 日）排序或"下榜后"行为——属不同签名，须独立实验。

**禁止**用下列方式继续消耗机时：归一化变体搜索（÷成交额、÷龙虎榜金额等消融位）、
窗口参数网格、提高覆盖率的部分列组合——均属消融位搜索，违反契约。

## 6. 引用的项目契约

- 列集审计/信号层筛选契约：列级效应（0~1pp）落噪声带内**不得开 WF 实验**；
- "加列默认带稀释成本"：新增因子必须先过信号层尺子（相对降幅 ≥9% 才值得跑全量 A/B）；
- 新增数据集 raw 存储契约：布局已在方案阶段写定（`docs/plans/top_inst_factor_plan.md`）并以此实现；
- 因子体检契约：候选清单是实验输入而非生产裁剪依据；负 IC 不等于坏因子，但**偏 IC 归零 = 无增量信息**（诊断标签 B）。
