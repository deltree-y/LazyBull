# PR: 纸面交易手工修正/回滚功能实现

## 版本信息
- **版本号**: v0.3.15 → v0.4.0（破坏性变更）
- **PR日期**: 2026-02-10

## 背景与目标

用户已开始正式纸面交易，需要在运行过程中支持手工修正持仓与现金，并在修正后从指定日期重新推导后续所有数据。这对于处理延迟买入/卖出、手工介入调整等场景至关重要。

### 修正的口径
**修正发生在 cut-off 日期的 run 之前**。即：修正后，从 cut-off 日期开始可以重新运行，确保数据一致性。

## 主要变更

### 1. 新增数据清理方法 `truncate_since`

**位置**: `src/lazybull/paper/storage.py`

新增 `PaperStorage.truncate_since(cut_off_date: str)` 方法，用于清理从指定日期开始的所有数据。

**清理范围**：
- `trades.parquet`: 删除 `trade_date >= cut_off_date` 的交易记录
- `nav.parquet`: 删除 `trade_date >= cut_off_date` 的净值记录
- `runs/`: 删除日期 >= cut_off_date 的 `t0_*.json` 和 `t1_*.json` 文件
- `instructions/`: 删除日期 >= cut_off_date 的指令文件
- `pending_buys.json`: 清空延迟买入队列
- `pending_sells.json`: 清空延迟卖出队列
- `rebalance_state.json`: 按规则回滚到合适的日期

**rebalance_state 回滚逻辑**：
- 仅当 `last_rebalance_date >= cut_off_date` 时才回滚
- 回滚到 cut_off 之前最近的一个 `t0_*.json` 记录日期
- 若 cut_off 之前无任何 t0 记录，则删除 rebalance_state（视为首次运行）

### 2. 新增 `adjust` 子命令

**位置**: `scripts/paper_trade.py`

新增 `adjust` 主命令及四个子命令，用于手工修正账户状态：

#### 2.1 `delete-position` - 删除持仓
```bash
python scripts/paper_trade.py adjust delete-position \
  --trade-date 20260210 \
  --ts-code 600519.SH
```

**行为**：
- 删除指定股票持仓
- 按买入价格释放资金：`cash += shares * buy_price`

#### 2.2 `update-position` - 更新持仓
```bash
python scripts/paper_trade.py adjust update-position \
  --trade-date 20260210 \
  --ts-code 600519.SH \
  --shares 1000 \
  --buy-price 1800.50
```

**行为**：
- 更新持仓股数和买入均价
- 自动计算现金变动：`delta_cash = old_shares*old_price - new_shares*new_price`
- 更新 `buy_cost = shares * buy_price`

#### 2.3 `add-shares` - 加仓
```bash
python scripts/paper_trade.py adjust add-shares \
  --trade-date 20260210 \
  --ts-code 600519.SH \
  --shares 500 \
  --price 1850.00
```

**行为**：
- 仅允许对已存在持仓加仓（否则报错并给出中文提示）
- 扣减现金：`cash -= add_shares * price`
- 加权更新买入价格：`new_price = (old_price*old_shares + price*add_shares) / (old_shares+add_shares)`
- 更新 `buy_cost = new_total_shares * new_buy_price`

#### 2.4 `cash` - 设置现金
```bash
python scripts/paper_trade.py adjust cash \
  --trade-date 20260210 \
  --set 500000.00
```

**行为**：
- 直接将账户现金设置为指定金额

#### 通用流程
所有 adjust 操作完成后：
1. 将 `account.json` 的 `last_update` 设置为 cut-off 日期
2. 调用 `truncate_since(cut_off_date)` 清理数据
3. 用户可从该日期重新运行 `run` 命令

## 技术细节

### truncate_since 实现要点
```python
def truncate_since(self, cut_off_date: str) -> None:
    # 1. 清理 parquet 文件（保留 < cut_off_date 的行）
    # 2. 删除文件系统上的 JSON 文件（>= cut_off_date）
    # 3. 清空队列文件（写入空列表）
    # 4. 智能回滚 rebalance_state
```

### adjust 命令统一模式
所有 adjust 子命令遵循统一模式：
1. 加载账户状态
2. 验证操作合法性（如持仓存在性、现金充足性）
3. 执行修正逻辑（更新 cash/positions）
4. 设置 `last_update = cut_off_date`
5. 保存账户状态
6. 调用 `truncate_since(cut_off_date)`
